### 为什么调整窗口后 Canvas 消失？

1. **`CanvasManager.resize()` 被触发**：调整窗口时，`CanvasManager` 确实重新计算了 `canvas.width` 和 `canvas.height`。
2. **Canvas 被自动清空**：当 `<canvas>` 元素的 `width` 或 `height` 属性被修改时，浏览器会**自动清除所有绘制内容**（这是 HTML5 Canvas 的标准行为）。
3. **没有注册重绘回调**：我们在 `main.ts` 中只调用了一次 `render()`，并没有通过 `canvasManager.onResize()` 注册任何回调。所以调整大小后，Canvas 是空的，且没人告诉它重新画。

---

## 修复方案：注册 resize 回调

修改 `src/main.ts`，在创建 `renderer` 后，将渲染函数注册到 `CanvasManager` 的 resize 事件中。

**在 `main.ts` 中找到 `render()` 函数定义和 `render()` 调用，添加 `canvasManager.onResize()`**：

```typescript
// src/main.ts

// ============================================================
// 5. 渲染
// ============================================================

function render() {
  const { width, height } = canvasManager.getSize();
  renderer.render(testCircuit, width, height);
}

// 首次渲染
render();

// ★ 关键修复：注册 resize 回调，窗口变化时自动重绘
canvasManager.onResize(() => {
  render();
});

// ============================================================
// 6. 状态栏坐标更新
// ============================================================
// ... 后面代码不变 ...
```

---

## 为什么这样有效？

| 时机 | 行为 |
|------|------|
| 启动 | 调用 `render()`，画布正常显示 |
| 窗口调整 | `CanvasManager.resize()` 触发 → 执行我们注册的 `onResize` 回调 → 调用 `render()` → 重新绘制所有内容 |
| F5 刷新 | 页面完全重新加载，再次执行启动流程，当然正常 |

修改后，无论你拖拽窗口到多大或多小，Canvas 都会自动重绘，UI 再也不会消失了。
